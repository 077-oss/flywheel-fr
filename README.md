# `flywheel-fr` 技能

`flywheel-fr` 用于飞轮储能系统（Flywheel Energy Storage, FES）参与多区电网频率调节的科研仿真。搭建 8 区等值机互联系统，含飞轮详细部件模型与组合调频控制，用 MATLAB 脚本（`ode15s`）数值求解，输出论文级配图与调频指标报告。

## 适合用它做什么

- 快速搭建"8 区等值机 + 集中式飞轮储能"的频率调节仿真，覆盖惯性响应、一次调频、二次调频三个层级。
- 生成可直接用于论文的频率响应曲线、RoCoF、各机功率分配、飞轮功率/SOC 配图（含有无飞轮对比）。
- 输出调频指标报告：频率最低点 nadir、RoCoF、稳态频差、调频里程。
- 替换真实飞轮/电网参数，研究不同惯量、下垂系数、飞轮容量下的调频效果。
- 做参数敏感性分析、新能源渗透场景（`scenario='renew'`）、多飞轮分布式接入等扩展。

## 工作方式

先确认仿真目标与参数，再运行、出图、核对指标，而不是直接套默认值：

- 系统规模：区域数 `nArea`（默认 8，可扩展）、各机惯量 `H`、调差系数 `Rg`、联络线同步功率系数 `Tij`。
- 飞轮模型：转子动力学 + PMSM 电磁转矩（`id=0` 矢量控制）+ SOC（转速平方关系）。
- 组合调频控制：虚拟惯量 `2Hfes·df/dt` + 一次调频下垂 `Kf·(f0-f)`（含死区 ±0.033 Hz + 测量延时）+ 二次调频 AGC。
- 扰动场景：阶跃负荷 `step`、新能源波动 `renew`，或两者叠加 `both`。
- 有无飞轮对比：`fr_sim('', 0)` 关闭飞轮跑基准，`fr_plot` 自动叠加对比，这是论文核心图。

## 典型请求

- "跑一遍默认 8 区系统 + 阶跃负荷扰动，出指标报告和论文图。"
- "把飞轮惯量改成 200 kg·m²，看看 nadir 和 RoCoF 怎么变。"
- "研究高比例新能源下的调频需求，用正弦扰动场景。"
- "对比 5 MW 和 1 MW 飞轮的调频效果，验证容量匹配规律。"
- "按参考文献搭一个等价 Simulink 模型验证脚本结果。"

## 你需要提供

- 真实飞轮参数（额定功率、转动惯量、转速范围）或电网参数（区域惯量、调差系数、联络线阻抗）。
- 扰动类型与幅值（阶跃负荷大小、新能源波动幅值/频率）。
- 一次调频要求（如下垂系数、死区）与虚拟惯量响应目标。
- 若只是复现默认结果，直接运行即可，无需提供参数。

## 产出

- 指标报告 `assets/output/report.txt`：nadir、RoCoF、稳态频差、调频里程、飞轮峰值功率与 SOC 变化。
- 4 张论文配图（`assets/output/`）：
  - `fig1_frequency_compare.png`：接入区频率响应，有无飞轮对比 + nadir 标注。
  - `fig2_rocof_compare.png`：RoCoF 对比，虚拟惯量压制效果。
  - `fig3_flywheel_power_soc.png`：飞轮输出功率与 SOC 变化。
  - `fig4_machine_power.png`：各区域等值机机械功率分配。

## 快速开始

```matlab
cd assets
R = fr_sim();        % 含飞轮仿真（默认 8 区 + 阶跃扰动）
fr_plot(R);          % 生成论文配图（自动跑无飞轮基准对比）
```

自定义参数：

```matlab
cd assets
R = fr_sim('params_example.m');   % 传入自定义参数文件
fr_plot(R);
```

## 环境要求

- MATLAB R2025a 或更高版本；无需额外工具箱（仅基础 MATLAB + `ode15s`）。

## 关键参数速查

| 参数 | 默认 | 含义 |
|---|---|---|
| `nArea` | 8 | 区域数 |
| `H` | 5.0 s | 各机惯量常数 |
| `Rg` | 0.05 | 调差系数（5%）|
| `Tij` | 1.5 | 联络线同步功率系数 |
| `Jfw` | 90 kg·m² | 飞轮转动惯量 |
| `Sbase` | 100 MW | 系统基准功率 |
| `Sfw` | 0.05 | 飞轮额定功率占比（5 MW）|
| `Hfes` | 3.0 s | 虚拟惯量常数 |
| `Kf` | 0.5 | 一次调频下垂系数 pu/Hz |
| `epsf` | 0.033 Hz | 一次调频死区 |
| `Tm` | 0.1 s | 频率测量延时 |
| `Ki_agc` | 0.3 | AGC 积分系数 |
| `dPL` | 0.10 | 阶跃负荷幅值 pu |

## 边界

- 飞轮是"高功率、低能量"器件：额定 1 MW、惯量 90 kg·m²（储能约 55 kWh）满功率放电仅约 3 分钟，仿真中 SOC 下降快是固有特性，不是模型错误。
- 飞轮容量需与虚拟惯量需求匹配：容量过小（如 1 MW）时虚拟惯量项被功率限幅截断，RoCoF 可能略增。
- 模型为等值聚合 + 联络线小扰动线性化 + `id=0` 矢量控制简化，适用于机电时间尺度调频研究，不覆盖电磁暂态。
- 本技能是纯脚本（`ode15s`）实现，不依赖 Simulink；Simulink 仅作为可选对照验证。
